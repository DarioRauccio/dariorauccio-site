# Accesso alle creatività Alfonsino Meta Ads

Le creatività della campagna **“Offerte d'estate”** sono organizzate in tre livelli:

1. **Preview animata web**  
   Apri `alfonsino-meta-ads.html` nel browser e vai alle sezioni “Accesso creatività”, “Varianti” e “Kit dinamico”. Le card animate mostrano il comportamento previsto per i video da usare in Feed, Reels e Stories.

2. **Matrice Dynamic Creative**  
   Usa `assets/meta-ads/alfonsino-dynamic-creative-matrix.csv` per copiare in Meta Ads Manager le combinazioni di:
   - variante visual,
   - placement,
   - formato,
   - durata,
   - primary text,
   - headline,
   - descrizione,
   - CTA,
   - motion hook.

3. **Specifiche per export video**  
   Usa `assets/meta-ads/alfonsino-video-variant-specs.json` come brief tecnico per produrre gli MP4 finali. Il file contiene formati, placement, titoli, descrizioni e motion per le 4 varianti.

## Importante

Nel repository sono presenti **preview animate e specifiche operative**, non file MP4 già renderizzati. Per caricare le creatività su Meta Ads, esporta le animazioni finali in questi formati:

- `9:16` per Instagram/Facebook Stories e Reels.
- `4:5` per Feed mobile.
- `1:1` per placement automatici o test aggiuntivi.

Durata consigliata: **6–10 secondi**, con logo visibile nel primo secondo e CTA finale “Apri l'app”, “Scopri le promo” o “Guarda i ristoranti”.
